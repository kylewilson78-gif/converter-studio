# Converter Studio

iPhone-first installable web app (PWA). Step 1: on-device converter.

- Images (incl. HEIC): JPG, PNG, WebP, AVIF, GIF, TIFF, BMP, ICO, PDF (single or combined), SVG (wrapped)
- Audio: MP3, WAV, M4A, FLAC, OGG, Opus
- Video: MP4, MOV, WebM, GIF, plus audio extraction
- Batches, Save/Share all, .zip download. Works offline after first use.

Install on iPhone: open the site in Safari, Share, Add to Home Screen.
